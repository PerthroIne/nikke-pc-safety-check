고위험 — 악성 에이전트 관련 증거가 발견되었습니다

이 PC에서 악성 에이전트가 실행되었거나 지속 실행 장치가 설치되었다고 볼 만한 증거입니다. 실제로 어떤 정보가 빠져나갔는지는 이 프로그램으로 알 수 없습니다. 원격 명령 실행 기능이 보고되었으므로 파일을 정리한 뒤에도 과거 노출 가능성은 남습니다. 깨끗한 다른 기기에서 계정 보호 조치를 진행하세요.

운영사와 무관한 도구입니다. 알려진 지표와 비교한 결과이며 안전을 보장하지 않습니다.

확인된 증거 단계: 에이전트 실행 흔적

[확인 못 함] 런처 설치 위치

폴더 탐색 제한에 걸려 일부 드라이브는 끝까지 찾지 못했습니다. 다른 곳에 또 설치했다면 폴더를 직접 선택하세요.

NSC-INSTALL
[해당 없음] 런처 설치 위치

니케 1곳, 같은 구조의 다른 런처 0곳을 찾았습니다.

NSC-INSTALL
[발견] 런처 실행 로그(debug.log) / 에이전트 실행 흔적

런처 로그에서 에이전트 실행 기록 1건을 찾았습니다. 첫 기록 11-01 01:20:37, 마지막 기록 11-01 01:20:37(로그 시각, 연도 없음). 과거에 실행되었다는 증거이며, 지금도 실행 중이라는 뜻은 아닙니다. 어떤 정보가 유출되었는지까지 증명하지는 않습니다.

NSC-LOG-EXEC
위치: <설치 폴더>\intl_service\debug.log
[확인 못 함] 다운로드 보조 로그(tinyget)

tinyget 로그 폴더가 없어 이 항목은 확인할 수 없습니다.

NSC-LOG-TINYGET
위치: <설치 폴더>\log\tinyget
[확인 못 함] 런처 Local Storage 상태 문자열

니케 런처 저장 폴더가 없어 확인할 수 없습니다. 런처를 쓴 적이 없거나 이미 지워졌을 수 있습니다.

NSC-LS-STATE
[확인 못 함] 런처 캐시의 로더 주소

니케 런처 캐시 폴더가 없어 확인할 수 없습니다.

NSC-CACHE-LOADER
[일치 없음] 사용자 COM 등록

이 사용자 하이브에서 해당 COM 항목을 찾지 못했습니다. HKLM의 같은 CLSID는 Windows 정상 항목이므로 판정에 쓰지 않습니다.

NSC-COM-KNOWN
[일치 없음] 의심 DLL

확인한 브라우저 폴더에서 해당 DLL을 찾지 못했습니다. PlatformExperienceHelper 폴더와 Chrome의 정상 EXE, LoadFeatures 파일은 정상일 수 있어 판정에 쓰지 않습니다.

NSC-DLL-SCAN
[일치 없음] 다른 CLSID의 사용자 COM 등록

일치하는 항목을 찾지 못했습니다.

NSC-COM-VARIANT
[일치 없음] 에이전트 임시 파일 이름

일치하는 이름을 찾지 못했습니다. 파일 내용은 열지 않습니다.

NSC-TEMP
[확인 못 함] 실행 중 프로그램의 로드 모듈

일치 항목은 없었지만 프로그램 2개는 권한 문제로 들여다보지 못했습니다.

NSC-PROC-MOD
[일치 없음] 현재 네트워크 연결

현재 연결 중 일치 항목이 없습니다. 공격 서버가 바뀌었으면 찾지 못합니다.

NSC-NET-CONN
[일치 없음] DNS 캐시

일치 항목이 없습니다. DNS 캐시는 금방 사라지므로 과거 기록을 뜻하지 않습니다.

NSC-DNS

# 사용자 안내서

컴퓨터에 익숙하지 않아도 따라 할 수 있도록 적었습니다. 순서대로 읽으세요.

## 먼저 알아 둘 것

**무슨 일인가요?** 공개 분석에 따르면 2026년 9월 27일부터 니케 PC 런처가 불러오는 Level Infinite CDN의 JavaScript 파일 일부가 변조되어 있었습니다. 일부 실행에서는 원격 제어 에이전트가 내려와 실행될 수 있었다고 합니다. 늦어도 10월 23일부터 실행 사례가 보고되었습니다.

**공식 발표인가요?** 아닙니다. 2026년 11월 4일 조사 기준으로 운영사의 확정·복구 공지를 확인하지 못했습니다. 다만 일부 공지 페이지는 자동으로 읽을 수 없어 공지가 없다고 단정할 수도 없습니다. [한국 공지](https://nikke-kr.com/news.html)와 [글로벌 공지](https://nikke-en.com/news.html)를 직접 확인하세요. 한국 서버, 글로벌 서버, 별도 유통판의 영향 여부도 확정되지 않았습니다.

**모바일만 했다면요?** 보고된 경로는 PC 런처입니다. 모바일 영향은 공개 분석에서 다루지 않았습니다.

## 실행 전

1. 니케 PC 런처가 켜져 있으면 닫고, 다시 열지 마세요.
2. 받은 파일의 해시를 [README](../README.md)대로 확인하세요.
3. 비밀번호 변경은 이 PC에서 하지 말고, 휴대전화 같은 다른 기기를 준비하세요.

SmartScreen 경고가 뜰 수 있습니다. 코드 서명이 없어서 나오는 경고입니다. 안전하다는 뜻도, 위험하다는 뜻도 아닙니다. 보안 기능을 끄지 마세요.

## 점검

**지금 점검하기**를 누르면 보통 1분 안에 끝납니다. 이 단계에서 파일이나 설정을 바꾸지 않습니다. 인터넷에 접속하지 않고 런처도 실행하지 않습니다. 언제든 **점검 취소**를 누를 수 있으며, 취소한 항목은 '확인 못 함'으로 표시됩니다.

설치 위치는 실행 중인 프로세스, 설치 정보, 바로가기, 흔한 경로에서 자동으로 찾습니다. 못 찾으면 결과 화면에서 폴더를 고르거나, 폴더를 창에 끌어다 놓으세요. PC 버전을 설치한 적이 없다면 **설치한 적 없음**을 누르세요.

## 결과별로 할 일

### ⛔ 고위험

1. 당황하지 않아도 됩니다. 이 화면이 곧 유출이 끝났다는 뜻은 아닙니다. 다만 그럴 가능성을 전제로 움직여야 합니다.
2. **권장 조치 실행**으로 남은 알려진 항목을 정리합니다.
3. **다른 기기에서** 계정 보호 안내를 진행합니다. 지갑, 이메일, 비밀번호 관리자, 금융, 게임, 개발 도구 순입니다.
4. 저장한 뒤 PC를 재시작하고 **다시 점검**합니다.
5. Windows 재설치를 검토합니다. 임의 명령 실행 기능이 있었기 때문에 알려진 항목을 지워도 다른 변경까지 되돌렸다고 볼 수 없습니다. 실행 로그가 있다면 재설치가 가장 확실합니다.

조치 후에도 로그 때문에 고위험이 남습니다. **정상입니다.** 현재 DLL과 COM 항목이 '일치 없음'이면 지속 실행 장치는 알려진 범위에서 제거된 것입니다.

### ⚠ 의심

단독으로는 판단하기 어려운 흔적입니다. 자동으로 지우지 않습니다. 항목별 설명을 읽고, 백신 전체 검사를 돌리고, 중요한 계정을 점검하세요. 런처가 변조 파일을 불러온 흔적이면 런처를 다시 열기 전에 캐시 정리가 필요합니다.

DNS 캐시 항목은 이 사고를 조사하다 해당 사이트를 열어도 생길 수 있어 약한 지표입니다.

### ⓘ 알려진 흔적 미발견

감염이 없다는 보장이 아닙니다. 게임을 지우면 debug.log도 사라지고, 새로운 변종이나 공격자가 지운 흔적은 찾지 못합니다. 9월 27일 이후 런처를 실행했다면 공식 공지가 나올 때까지 런처를 열지 말고 중요한 계정의 2단계 인증을 점검하세요.

### ❔ 점검 불완전

각 항목의 '해 볼 일'을 따르세요.

| 이유 | 해결 |
|---|---|
| 설치 위치를 못 찾음 | 폴더 선택, 또는 '설치한 적 없음' |
| debug.log 없음 | 게임을 지웠거나 실행한 적이 없으면 정상적으로 없을 수 있습니다. 기록이 없어 판단할 수 없다는 뜻입니다 |
| 파일 잠김 | 런처를 닫고 다시 점검. 안 되면 재시작 후 다시 점검 |
| 접근 거부 | 본인 계정으로 일반 실행했는지 확인 |
| 다른 계정으로 실행 중 | 로그인한 사용자 기준으로 점검은 하지만 조치는 하지 않습니다. 본인 계정에서 다시 여세요 |

## 조치 화면

바뀌는 내용 전체가 체크 상자로 나옵니다. **시험 실행**은 조건만 확인하고 아무것도 바꾸지 않습니다.

| 항목 | 기본 선택 | 알아 둘 점 |
|---|---|---|
| 사용자 COM 등록 제거 | 대상이 있으면 선택 | 이 계정의 항목 하나만. 관계없는 값이 함께 있으면 멈춥니다 |
| 의심 DLL 격리 | 대상이 있으면 선택 | 사용 중이면 '재부팅 후 처리 필요' |
| 런처 전용 캐시 정리 | 고위험·의심일 때 선택 | 치료가 아닙니다. 로그인과 표시 설정이 초기화될 수 있습니다. 런처가 켜져 있으면 멈춥니다 |
| 알려진 공격 서버 차단 | 고위험·의심일 때 선택 | 관리자 승인 필요. 완전 격리가 아닙니다 |
| 런처 외부 통신 차단 | 선택 안 됨 | 차단 중에는 런처가 동작하지 않습니다 |
| Defender 빠른·전체 검사 | 빠른 검사만 선택 | 다른 백신을 쓰면 나오지 않습니다 |
| Defender 오프라인 검사 | 선택 안 됨 | **곧바로 재부팅됩니다.** 작업을 먼저 저장하세요 |

결과 화면의 표시는 다음 뜻입니다.

- **완료**: 처리하고 결과까지 확인했습니다.
- **재부팅 후 처리 필요**: PC를 재시작하고 런처를 열지 말고 다시 점검하세요.
- **안전을 위해 중단**: 점검 뒤 대상이 바뀌었습니다. 아무것도 바꾸지 않았으니 다시 점검하세요.
- **실패**: 이유를 읽고 다시 시도하세요. UAC를 취소했다면 그 항목만 바뀌지 않습니다.
- **수동 조치 필요**: 자동으로 처리하면 위험해 멈췄습니다. 전문가에게 확인하세요.

방화벽이 꺼져 있거나 조직 정책이 막으면 '실패'로 표시합니다. 규칙이 동작하지 않는데 성공으로 보이지 않게 하기 위해서입니다.

Defender 검사가 끝나도 발견 여부는 **Windows 보안 > 바이러스 및 위협 방지 > 보호 기록**에서 확인하세요. 미탐지여도 찾아 둔 증거가 취소되지 않습니다.

**예방 설정 되돌리기**는 이 프로그램이 추가한 방화벽 규칙과 hosts 줄만 지웁니다. 다른 프로그램의 설정과 직접 쓴 hosts 줄은 보존합니다.

## 다른 브라우저, Linux, Steam Deck

- 보고된 지속 실행 DLL은 Chrome 경로입니다. 분석 자료에 따라 다른 Chromium 브라우저 경로를 언급하기도 해서, 같은 구조의 파일이 있으면 의심으로 알려 줍니다. Chrome이 없어도 에이전트 자체는 동작할 수 있었다고 보고되었습니다.
- 저장 비밀번호 수집 대상으로 Chrome, Edge, Brave, Vivaldi, Opera, Firefox가 보고되었습니다.
- Linux와 Steam Deck(Proton)은 이 프로그램이 지원하지 않습니다. Proton이 보호하지 못한다는 보고가 있으니 실행한 적이 있다면 홈 폴더의 비밀을 노출된 것으로 보고 다른 기기에서 계정을 보호하세요.

## 자주 묻는 질문

**공지대로 경로를 찾아봤는데 아무것도 없어요. 다 지워진 건가요?** 점검만 해서는 아무것도 지워지지 않습니다. '선택한 조치 실행'까지 눌렀다면 체크한 항목이 처리되어 공지 경로에서 보이지 않습니다. 런처 캐시 정리는 고위험이나 의심일 때 기본 체크라 `tbs_cache`가 사라졌을 수 있습니다. v0.1.1부터는 다시 점검할 때 이전 조치 내역을 보여 줍니다. `%LOCALAPPDATA%\NikkeSafetyCheck` 폴더가 있으면 조치 기록도 볼 수 있습니다. 설치 폴더의 `debug.log`는 프로그램이 지우지 않습니다. 안 보인다고 안전하다는 뜻은 아니며, 과거 노출 가능성은 그대로입니다.

**게임을 지우면 해결되나요?** 아닙니다. 지속 실행 항목과 런처 저장소는 게임 폴더 밖에 있고, 지우면 가장 강한 증거인 debug.log만 사라집니다. 점검 전에 지우지 마세요.

**백신에서 안 잡히면 괜찮은가요?** 그것만으로 안심할 수 없습니다. 이 프로그램의 결과와 함께 보세요.

**이 프로그램을 쓰면 계정이 제재되나요?** 게임 파일을 바꾸지 않고 게임을 실행하지도 않습니다. 다만 운영사 입장을 확인한 것은 아닙니다.

**비밀번호를 입력하라고 하나요?** 절대 그러지 않습니다. 그런 화면이 뜨면 가짜입니다.

**9월 27일 이후 런처를 켰으면 무조건 감염인가요?** 아닙니다. 공개 분석에서도 일부 실행에서만 내려왔다고 합니다. 날짜는 점검이 필요한 이유일 뿐이고 판정은 PC의 증거로 합니다.

**다른 게임도 위험한가요?** 2026년 11월 4일 12시 19분 보도까지 다른 게임의 피해 근거는 확인하지 못했습니다. 다만 변조 파일 일부가 공용 폴더에 있었고 공격자의 접근 범위가 밝혀지지 않아 안전하다고 볼 수도 없습니다. 이 프로그램은 같은 구조의 다른 런처 폴더도 같은 지표로 찾아봅니다. 게임 설치만으로 판정하지 않고, 구조가 다르거나 공격 방식이 다르면 찾지 못합니다. 다른 게임을 쓴다면 해당 운영사 공지를 함께 확인하세요.

**다른 런처에서 흔적이 나오면 어떻게 하나요?** 결과에 '[니케 외 런처 폴더]'로 표시됩니다. 등급은 니케와 같은 기준이지만 자동으로 정리하지 않습니다. 그 런처를 열지 말고, 다른 기기에서 계정을 보호하고, 백신 전체 검사와 운영사 공지 확인을 진행하세요.

**공격 서버가 멈췄다던데 끝난 건가요?** 응답이 멈춘 것이 공격 종료나 복구를 증명하지는 않습니다.

**증거 단계는 무엇인가요?** 어디까지 확인됐는지 보여 주는 표시입니다. 시도, 다운로드 성공, 실행 흔적, DLL 설치, 현재 로드로 나뉘며 모든 PC에서 순서대로 나타나지는 않습니다. DLL이 있다고 지금 실행 중인 것은 아닙니다.

**PC가 회사 소유입니다.** 직접 조치하지 말고 IT·보안 담당자에게 바로 알리세요.

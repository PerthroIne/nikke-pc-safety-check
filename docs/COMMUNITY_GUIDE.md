# 온라인 커뮤니티 안내 가이드

니케 커뮤니티, 디스코드, 오픈채팅에 이 도구를 소개할 때 쓰는 글입니다. 복사해서 그대로 쓸 수 있습니다.

## 올리기 전 확인

- [ ] 최신 [릴리스](https://github.com/PerthroIne/nikke-pc-safety-check/releases/latest)의 버전과 해시를 글에 맞게 넣었다.
- [ ] 운영사 공식 공지가 새로 나왔는지 [한국](https://nikke-kr.com/news.html), [글로벌](https://nikke-en.com/news.html) 공지를 확인했다. 나왔다면 공식 안내를 맨 위에 둔다.
- [ ] 게시판 규칙에서 외부 실행 파일 링크가 허용되는지 확인했다. 금지라면 저장소 링크만 올리거나 운영진에게 먼저 묻는다.
- [ ] **exe 파일을 직접 첨부하거나 재업로드하지 않고** 저장소 링크만 건다.
- [ ] 글에 내 로그, 사용자 이름, 결과 파일 원문을 넣지 않았다.

## 표준 글 (게시판용)

**제목:** [비공식] 니케·같은 구조 PC 런처 사고 흔적 점검 프로그램 공유 (오픈소스)

> 니케 PC 런처 공급망 사고와 관련해, 공개 분석에 나온 흔적을 PC에서 확인하는 **비공식** 프로그램을 공유합니다. 운영사와 관련이 없고 공식 발표에 기반한 것도 아닙니다. 소스가 모두 공개되어 있습니다.
>
> **받기:** https://github.com/PerthroIne/nikke-pc-safety-check
>
> **범위:** 확인된 피해는 니케 PC 런처입니다. 다른 게임의 피해 근거는 아직 확인하지 못했지만 안전하다고 볼 수도 없어서, 같은 구조의 다른 런처 폴더도 같은 지표로 찾아봅니다. 니케 외 폴더는 읽기만 하고 자동으로 정리하지 않습니다.
>
> **이런 분께:** 2026년 9월 27일 이후 니케 PC 런처를 실행한 적이 있는 분. 명령어를 직접 입력하지 않고 확인하고 싶은 분.
>
> **하는 일**
> - 더블클릭하고 '지금 점검하기'만 누르면 됩니다. 설치가 필요 없습니다.
> - 런처 로그, 런처 저장소, Chrome 폴더의 의심 DLL, 사용자 레지스트리 등록을 확인합니다.
> - 고위험 / 의심 / 알려진 흔적 미발견 / 점검 불완전으로 나눠 쉬운 말로 설명합니다.
> - 원하면 변경 목록을 확인한 뒤 알려진 항목을 격리하고 차단 규칙을 추가합니다.
> - 다른 기기에서 할 계정 보호 순서를 알려 줍니다.
>
> **하지 않는 일**
> - 점검 단계에서는 아무것도 바꾸지 않습니다.
> - 인터넷으로 아무것도 보내지 않습니다.
> - 비밀번호나 복구 문구를 묻지 않습니다. 브라우저 비밀번호와 쿠키 파일을 열지 않습니다.
>
> **꼭 읽어 주세요**
> - **'알려진 흔적 미발견'은 안전 보장이 아닙니다.** 고위험이 나와도 실제 유출이 확정된 것은 아닙니다.
> - 조치를 해도 과거 노출 가능성은 없어지지 않습니다. 실행 기록이 있으면 다른 기기에서 비밀번호 변경과 세션 종료를 하고, Windows 재설치도 검토하세요.
> - **코드 서명이 없어** SmartScreen이나 백신이 경고할 수 있습니다. 보안 기능을 끄지 마세요. 해시를 확인하고 스스로 판단하세요. 믿기 어려우면 안 쓰셔도 됩니다.
> - 이 사고를 노린 **가짜 치료 프로그램**이 돌 수 있습니다. 위 저장소의 릴리스에서만 받으세요.
> - 일회용 Windows VM에서 무해한 가짜 파일로 테스트했습니다. 실제 악성코드로 시험하지 않았고, 모든 환경에서 검증되지는 않았습니다.
> - 점검 전에 게임을 지우지 마세요. 가장 강한 증거인 로그가 함께 사라집니다.
>
> **근거 자료:** [MotherSphere 보고서](https://gist.github.com/MotherSphere/d6c049a09ba8ac3085c51ee9df24a4e5), [WormW 분석](https://github.com/WormW/nikke_malware_analysis). 모두 개인 분석입니다. 글 작성 시점까지 운영사의 확정·복구 공지는 확인하지 못했으니 공식 공지도 직접 확인해 주세요.
>
> 결과를 공유할 때는 로그 원문 대신 프로그램의 '결과 저장' 파일을 읽어 본 뒤 필요한 부분만 올려 주세요. 오탐이나 새 정보는 GitHub Issues로 알려 주세요.

## 짧은 글 (디스코드, 오픈채팅)

> 니케 PC 런처 사고 흔적 점검 프로그램(비공식, 오픈소스)입니다. 더블클릭 후 '지금 점검하기'만 누르면 되고, 점검은 PC를 바꾸지 않고 인터넷도 쓰지 않습니다.
> https://github.com/PerthroIne/nikke-pc-safety-check
> ⚠ 운영사와 무관합니다. '미발견'이 안전 보장은 아닙니다. 코드 서명이 없어 경고가 뜰 수 있으니 보안 기능은 끄지 말고, 위 링크에서만 받으세요. 비밀번호를 묻는 화면이 나오면 가짜입니다.

## 자주 나올 질문과 답변

**Q. 믿을 수 있나요?**
A. 믿으라고 하기보다 확인하실 수 있게 공개했습니다. 소스와 빌드 기록, 테스트 결과, 해시가 모두 저장소에 있습니다. 코드 서명은 없습니다. 걱정되면 직접 빌드하거나 쓰지 않으셔도 됩니다.

**Q. 백신이 악성이라고 합니다.**
A. 레지스트리와 hosts, 방화벽을 다루는 서명 없는 프로그램이라 오탐이 날 수 있습니다. 다만 오탐이라고 단정해 드릴 수 없습니다. 보안 기능을 끄지 마세요. 해시가 릴리스와 같은지 확인하고, 다르면 쓰지 마세요. 저장소 Issues로 알려 주세요.

**Q. 미발견이 나왔으니 안전한 거죠?**
A. 알려진 지표가 없다는 뜻뿐입니다. 게임을 이미 지웠다면 로그가 없어 확인이 제한됩니다. 9월 27일 이후 실행했다면 중요한 계정의 2단계 인증을 점검하세요.

**Q. 고위험이 나왔습니다. 털린 건가요?**
A. 에이전트가 실행되었다는 증거이지, 무엇이 유출되었는지 증명하지는 않습니다. 다만 유출 가능성을 전제로 다른 기기에서 계정을 보호하세요. 지갑, 메인 이메일, 비밀번호 관리자, 금융, 게임·개발 도구 순입니다. Windows 재설치도 검토하세요.

**Q. 조치했는데 왜 계속 고위험인가요?**
A. 로그는 과거 기록이라 남습니다. DLL과 COM 항목이 '일치 없음'이면 현재 장치는 알려진 범위에서 정리된 것입니다. 로그를 일부러 지우지 마세요.

**Q. 공지대로 찾아봤는데 아무것도 없어요. 다 지워진 건가요?**
A. 점검만 해서는 아무것도 지워지지 않습니다. '선택한 조치 실행'까지 눌렀다면 체크한 항목이 처리되어 안 보이는 게 정상입니다. `%LOCALAPPDATA%\NikkeSafetyCheck` 폴더가 있으면 조치 기록이 있는 것이고, 설치 폴더의 `debug.log`는 지우지 않으니 `k2f_chan`을 검색해 보세요. 안 보인다고 안전하다는 뜻은 아닙니다.

**Q. 게임을 지우고 새로 깔면 되나요?**
A. 그것만으로는 부족합니다. 관련 항목이 게임 폴더 밖에 있습니다. 공식 복구 공지 전까지 런처를 열지 않는 것을 권합니다.

**Q. 9월 27일 이후 켰으면 다 감염인가요?**
A. 아닙니다. 공개 분석에서도 일부 실행에서만 내려왔다고 합니다. 날짜는 점검이 필요한 이유이고 판정은 증거로 합니다.

**Q. 다른 텐센트 게임도 당했다던데요?**
A. 그런 주장은 있지만 게임별 기술 증거를 확인하지 못했습니다. 안전 보장도, 거짓 확정도 아닙니다. v0.2.0은 같은 구조의 다른 런처 폴더를 같은 지표로 찾아보지만, 설치만으로 판정하지 않고 구조나 공격 방식이 다르면 찾지 못합니다. 해당 게임의 운영사 공지도 확인하세요.

**Q. 맥, 스팀덱, 모바일은요?**
A. 이 도구는 Windows x64 전용입니다. Proton으로 런처를 실행했다면 보호되지 않는다는 보고가 있으니 계정 보호를 진행하세요. 모바일은 공개 분석에서 다루지 않았습니다.

**Q. 내 결과를 봐 주세요.**
A. 공개 게시판에 로그 원문이나 기록 폴더를 올리지 마세요. '결과 저장' 파일을 읽어 본 뒤 등급과 규칙 ID 정도만 공유해 주세요. 저도 전문가의 포렌식을 대신할 수 없습니다. 회사 PC라면 담당 부서에 바로 알리세요.

## 쓰지 말아야 할 표현

| 쓰지 마세요 | 이유 | 대신 |
|---|---|---|
| 공식, 운영사 제공, 시프트업 인증 | 사실이 아닙니다 | 비공식 커뮤니티 도구 |
| 치료, 백신, 완치, 이걸로 해결 | 알려진 항목만 다룹니다 | 점검과 대응 보조 |
| 100% 안전, 감염 없음 | 보장할 수 없습니다 | 알려진 흔적 미발견 |
| 전원 해킹, 모든 정보 유출 확정 | 근거가 없습니다 | 실행되었다면 노출 가능성 있음 |
| 다른 게임도 전부 감염 / 다른 게임은 안전 | 게임별 증거가 없습니다 | 미확인 |
| 서버가 죽었으니 끝 | 종료나 복구의 증명이 아닙니다 | 서버 응답 중단이 관찰됨 |
| 여러 분석이 교차 검증 | 2차 자료 다수가 같은 원문을 인용합니다 | 개인 분석, 주요 원문 표기 |
| 한국 서버도 확정 / 글로벌만 해당 | 영향 범위는 미확정입니다 | 영향 범위 미확정 |
| 백신 끄고 실행하세요 | 위험한 습관을 가르칩니다 | 해시 확인 후 판단 |
| 특정 인물·회사가 범인 | 귀속은 확인되지 않았습니다 | 언급하지 않기 |

운영사나 게임 로고, 캐릭터 이미지를 글이나 썸네일에 넣지 마세요. 공식 도구로 오해받을 수 있습니다.

## 올린 뒤 관리

- 운영사 공지가 나오면 글 맨 위에 링크를 추가하고, 공지와 다른 내용은 고칩니다.
- 새 지표가 나오면 `iocs.json`을 고쳐 새 버전을 내고, 글의 버전을 수정합니다. 예전 버전 사용자에게도 다시 받으라고 안내합니다.
- 오탐이나 잘못된 조치 제보를 받으면 먼저 고정 댓글로 알리고 원인을 고칩니다.
- 다른 사람이 올린 재업로드 파일을 발견하면 원본 저장소로 안내합니다.
- 공격 서버에 접속해 보거나, 피해자 정보를 모아 공개하지 마세요.

# 테스트 결과

자동 실행 기록은 [`ci-results` 브랜치](https://github.com/PerthroIne/nikke-pc-safety-check/tree/ci-results)와 [Actions](https://github.com/PerthroIne/nikke-pc-safety-check/actions)에서 볼 수 있습니다. 로그, 화면, 샘플 공유 보고서가 들어 있습니다.

**실제 악성코드나 공격 서버는 쓰지 않았습니다.** 내용이 무해한 텍스트인 가짜 파일로 검증했습니다. 해당 파일은 진짜 DLL이 아니며 불러오지 않습니다.

## 실행한 것

환경: GitHub Actions `windows-2025` 일회용 VM(Windows Server 2025, 빌드 26100, x64), .NET SDK 10.0.403. 테스트 후 VM은 폐기됩니다.

| 묶음 | 결과 | 내용 |
|---|---|---|
| 엔진 회귀 테스트 | 43개 통과 | 프롬프트의 필수 14개 시나리오와 독립 검토에서 나온 사례. Linux와 Windows에서 모두 실행 |
| Windows 통합 테스트 W01~W11 | 12개 통과 | 실제 HKCU와 파일로 점검→조치→재점검, 격리 파일 ACL, 정션 감지, 서명 판정, 파일 ID, 보조 인자 검증, 실제 방화벽·hosts 적용과 복구, Defender 조회, 화면 렌더링 |
| 일반 권한 토큰 W02b | 통과 | `runas /trustlevel:0x20000`으로 관리자 권한 없는 토큰에서 사용자 범위 점검과 조치 실행 |
| 게시된 EXE 흐름 W12 | 통과 | 단일 실행 파일을 UI 자동화로 조작: 점검, 조치 계획, 실행, 관리자 보조를 통한 방화벽·hosts 적용, 되돌리기, 재점검 |

### 필수 시나리오 대응

| # | 시나리오 | 테스트 |
|---|---|---|
| 1 | 정상 부모 폴더/EXE만 | 01 |
| 2 | 정상 HKLM CLSID만 | 02, W03 |
| 3 | 일치하는 COM/DLL, 올바른 SID | 03, W02 |
| 4 | 해시 불일치 변형 | 04, 04b, 04c, 04d, 24 |
| 5 | 로그만 과거 흔적 | 05, 05b, 05c, 05d |
| 6 | 경로 없음, 거부, 잠금, 취소 | 06, 06b~06e, 22, 23 |
| 7 | 다른 관리자 자격 | 07 (가짜 저장소, 실제 UAC 아님) |
| 8 | 32/64비트, 다중 설치, 비영문·긴 경로 | 08, 08b |
| 9 | reparse, 경로 이탈, 파일 교체 | 09, 09b, 09c, W04 |
| 10 | 반복 실행, 기존 설정 보존 | 10, W09 |
| 11 | 중간 실패, 재부팅 전후 | 11, 11b, 27, 28 (재부팅은 시뮬레이션) |
| 12 | 공유 보고서 | 12, 26, W02 |
| 13 | 오프라인, Defender 미사용, 권한 거부 | 13, W10 |
| 14 | 명령·인자 주입 | 14, 16, W07, W08 |

독립 검토를 별도로 한 번 받아 앱 충돌, 불완전 점검의 '미발견' 표시, 알려진 해시 등급 하향, hosts 쓰기 안전성, 보고서 경로 노출, 재부팅 알림 소실 등을 고쳤습니다.

## 실행하지 못한 것

| 항목 | 상태 |
|---|---|
| **일반 Windows 11 데스크톱 PC** | 미실행. Server 2025는 같은 빌드 계열이지만 같은 환경이 아닙니다 |
| Windows 10 | 미실행 |
| **실제 UAC 승인 창, 일반 사용자가 승인·취소하는 흐름** | 미실행. VM은 UAC 창 없이 승격됩니다. 취소 처리는 코드로만 구현 |
| 다른 관리자 계정을 UAC에 입력하는 경우 | 실제로는 미실행. 대상 해석은 코드와 가짜 저장소로만 검증 |
| 실제 악성 DLL, 브라우저에 로드된 DLL, 실제 재부팅 전후 | 미실행 |
| 실제 니케 런처 설치본 | 미실행. 폴더 구조와 로그 형식은 공개 보고서 기준이며, 설치 정보 이름이나 `nikke_launcher.exe` 위치는 실제와 다를 수 있습니다 |
| Defender 오프라인 검사 | 미실행. 재부팅을 일으키기 때문 |
| Defender 검사 완료까지 | 시작만 확인 |
| 타사 백신 환경, 조직 정책, 방화벽 꺼짐 | 미실행. 코드로만 구현 |
| SmartScreen과 백신의 실제 반응 | 미확인 |
| 관리자 보조의 임시 폴더 모듈 확인 | W12에서 정상 경로만 통과 확인. 차단 경로는 미실행 |

실제 PC에서 문제가 생기면 [Issues](https://github.com/PerthroIne/nikke-pc-safety-check/issues)로 알려 주세요. 로그 원문과 개인 정보는 올리지 마세요.
